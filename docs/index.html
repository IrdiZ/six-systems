How this works

A simulator writes each department's files in its native format (HL7v2, EDIFACT-style lab files, DICOM CT, DICOM screen captures, PDF reports, a proprietary slide file) and a hidden answer key. An assembler reads the files, links them to patients, harmonises codes and units, reads numbers out of images and PDFs, and is then scored against the answer key it never saw.

Honest limits

All data is synthetic; all organisations are fictional. File formats are simplified, realistic in shape, not certified. OCR succeeds this often only because we generated clean images. This shows the shape of the problem, not any hospital's real data flows. Not a medical device.
