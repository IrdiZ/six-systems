How this works

A simulator writes each department's files in its native format (HL7v2, EDIFACT-style lab files, DICOM, PDF reports, a proprietary slide file) and a hidden answer key. An assembler reads the files, links them to patients, harmonises codes and units, and reads numbers out of images and PDFs. The answer key then scores the result. The assembler never sees it.

Limits

All data is synthetic and all organisations are fictional. File formats are simplified: realistic in shape, not certified. OCR works here because the images are clean. This is not a medical device.
